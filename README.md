# Dossier Manager for OJS 3.5

An OJS plugin for planning **dossiers**: groups of commissioned articles that are published together, such as special issues, thematic sections, review symposia or forums.

Editors plan a dossier with its target issue, submission deadline and planned contributions, invite the contributors by email, and track the submissions. Each contributor gets a personal submission link that starts a normal OJS submission attached to their planned contribution. Contributors are reminded before the deadline and at regular intervals after it.

**Status:** in planning. The specification is in [issue #1](https://github.com/cboulanger/ojs-dossier-manager/issues/1) and in [docs/specs](docs/specs/2026-11-22-dossier-manager-design.md).

The plugin follows the patterns of [Book Review Manager](https://github.com/cboulanger/ojs-book-review-manager).
